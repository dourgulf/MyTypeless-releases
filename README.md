# MyTypeless

Voice input for the macOS menu bar: hold the right ⌘ key and speak; on release, MyTypeless transcribes, polishes and
types the text into the focused field.

This repository only hosts signed and notarized builds. The source code is kept in a separate repository.

## Download

Get the latest DMG from [Releases](https://github.com/dourgulf/MyTypeless-releases/releases).

## Install

1. Open the DMG and drag **MyTypeless** to **Applications**.
2. Launch it and allow **Microphone** access when asked.
3. Enable MyTypeless under **System Settings → Privacy & Security → Accessibility**.
4. Enter your DashScope API key in Settings.

Requirements: macOS 14 or later, Apple Silicon or Intel.

Each release lists the DMG's SHA-256; verify with `shasum -a 256 -c MyTypeless-<version>.dmg.sha256`.
